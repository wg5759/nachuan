# Governance

Nachuan is currently maintainer-led.

- Maintainers decide release scope, security boundaries, compatibility, and
  roadmap after reviewing reproducible evidence.
- Significant architecture decisions are recorded as ADRs or versioned design
  documents before implementation.
- Security owners may block a change that weakens identity, credential,
  financial, channel, tenant, audit, plugin, or update boundaries even when the
  feature otherwise works.
- No model vote, star count, or user report replaces technical verification.
- Maintainer status is earned through sustained, reviewable contributions and
  responsible handling of security and user data.

The project may move to a broader foundation or elected governance model after
the contributor and maintainer base is large enough to support it.
